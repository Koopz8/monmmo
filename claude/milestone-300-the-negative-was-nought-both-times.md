# Milestone 300: the negative was nought, both times

297 measured a caveat and the floor refused it. 298 found the same question read three ways. 299
found the column 298 had not printed. This closes the seam: the two things 298 and 299 left owed,
both measured, and **both come back nought**.

## The barrier that was never in the run

`WhoTheCompareBelongsTo.WhatStoodInTheWay` decides what stood between a call and the compare that
was credited across it — the reading behind `--routines`' three verdicts. **It had no contiguity
check at all**, and 299 took the distance off it. So the walk could run off the end of one script
and name a thing in the way belonging to whatever block the reader concatenated next.

That is 74's rule turned on the milestone that came before: *when you teach a reader to stop being
wrong in one direction, ask what the other direction now does.* 299 widened a walk with no
contiguity check and did not ask.

Measured: **nought.**

```
  140 site(s) sorted by WhatStoodInTheWay
    the thing in the way is in the SAME contiguous run: 140
    it is past a gap — another script entirely:           0
    how far it reaches: median 3, most 26 command(s)
```

The fault is real, the blast radius is nought, and the rule is decided on adjacency now anyway —
because **a rule the cartridge never exercises is a rule no break can be aimed at** (57), so the
fixture carries a counterexample the file does not contain. The three verdicts are unmoved at
97 / 38 / 5.

## The call that did not write the slot

214 made a plain `call` a barrier in the ANSWER scan, because the block it jumps into can answer.
The ARGUMENT scan has no such barrier and the same argument applies — a called block can write an
argument slot exactly as it can write the answer variable — and 298 printed *13 of 244 credited
places have a call or a branch between the value and the call* without following one.

Followed one level:

```
      0   a GOTO — the call is not reached from the value at all
      3   a conditional jump — the call is reached on the arm it does not take, value intact
      5   a call whose block writes NO argument slot — the credit stands
      5   a call whose block calls something of its own — one level was not enough
      0   a call whose block WRITES that very slot — the credit is WRONG
```

> **Nought of the thirteen is a value the block overwrote.** Five are unread because the block
> calls something of its own; the other eight come back clean. **298's error bar of 13 is really
> 5**, and not one credit in this project was wrong.

That is 30's rule: the reading that can only produce a list produces one whether or not there is
anything there, and the question worth asking is the one whose "no" is worth as much as its "yes".
Both halves of this milestone are that answer.

`SpecialCalls.WhichSlotsACallWrites` is the companion to `WhatACallLeaves` and it takes 252's
measured write-operand table rather than a fifth private copy of it — which is what 298 was about.

## What this seam closed

Four milestones on one question. `SpecialCalls.Before` had a chosen distance at 294; it has two
read rules and no distance now, and so do all three copies of it. `SpecialCalls.After` had one; it
has none. `SpecialContracts.ComparedAfter` had one; it has a read rule — *a compare belongs to the
last answerer before it* — and no distance. `WhoTheCompareBelongsTo` shares the setting and has the
contiguity it never had. **Not one number in any of those readings is chosen here any more.**

What it cost, in order: 44 -> 62 -> 39 -> 37 routines handed a value (296), 26 places and 12
routines declined against their floor (297), 37 in one section against 44 in another reconciled
(298), 148 / 27 / 81 / 19 corrected to 454 / 39 / 140 / 25 (299), and nought and nought (300).
